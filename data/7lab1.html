Интерактивная лабораторная работа №1

Тема: Определение цены деления измерительного прибора

Цель: Научиться определять цену деления различных измерительных приборов и измерять физические величины с учётом погрешности.

Инструкция по выполнению

  1. Для каждого из трех приборов внимательно изучите шкалу. При каждой перезагрузке страницы шкала генерируется случайным образом.
  2. Вычислите цену деления для каждого прибора и запишите результат в соответствующую ячейку таблицы.
  3. Используя ползунки, установите случайное значение для каждого прибора.
  4. Определите показания прибора и его погрешность (равную половине цены деления). Запишите результат в таблицу.
  5. Когда все поля будут заполнены, нажмите кнопку "Проверить". У вас есть две попытки.

Ход работы:

1. Измерение длины ластика линейкой

Перемещайте ползунок, чтобы изменить длину ластика. Определите цену деления и результат измерения, после чего впишите их в таблицу.

Ластик

2. Измерение объема жидкости

Перемещайте ползунок, чтобы "налить" воду. Определите цену деления и объем, после чего впишите их в таблицу.

3. Измерение температуры

Перемещайте ползунок, чтобы изменить температуру. Определите цену деления и показания, после чего впишите их в таблицу.
