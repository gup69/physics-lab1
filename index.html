Механика

• Равноускоренное движение: s = v0t + (at2)/2
• Скорость при ускорении: v = v0 + at
• Второй закон Ньютона: F = m · a
• Закон всемирного тяготения: F = G · (m1 · m2) / r2
• Импульс тела: p = m · v
• Механическая работа: A = F · s · cos(α)
• Кинетическая энергия: Ek = (m · v2) / 2
• Потенциальная энергия: Ep = m · g · h

Термодинамика и МКТ

• Уравнение Менделеева — Клапейрона: P · V = (m / M) · R · T
• Основное уравнение МКТ: P = (1/3) · n · m0 · v2
• Средняя кинетическая энергия: Ek = (3/2) · k · T
• Первый закон термодинамики: Q = ΔU + A
• Работа в термодинамике: A = P · ΔV
• Количество теплоты: Q = c · m · ΔT + λ · m + L · m
• КПД тепловой машины: η = A / Q1 = (T1 - T2) / T1

Электродинамика

• Закон Кулона: F = k · (|q1| · |q2|) / r2
• Напряженность поля: E = F / q
• Закон Ома для участка цепи: I = U / R
• Закон Ома для полной цепи: I = ε / (R + r)
• Мощность электрического тока: P = U · I = I2 · R
• Сила Ампера: FA = I · B · l · sin(α)
• Сила Лоренца: FL = q · v · B · sin(α)

Оптика и Волны

• Закон преломления света: n2 / n1 = sin(α) / sin(β)
• Формула тонкой линзы: 1 / F = 1 / d + 1 / f
• Оптическая сила линзы: D = 1 / F
• Дифракционная решетка: d · sin(φ) = k · λ
• Длина волны: λ = v · T = v / ν

Ядерная физика

• Дефект масс: Δm = [Z·mp + (A - Z)·mn] - Mядра
• Энергия связи ядра: Eсвяз = Δm · c2
• Закон радиоактивного распада: N(t) = N0 · 2-t / T1/2
• Альфа-распад: AZX → A-4Z-2Y + 42He
• Бета-минус распад: AZX → A+1Z+1Y + e- + ṽ
